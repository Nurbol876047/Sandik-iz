# Сандық із: интернеттегі ізіміз (Цифровой след)

Веб-платформа для школьного научного проекта конкурса «Зерде» (информатика, 5–7 класс).
Цель проекта: обучение детей основам кибергигиены, понятие "цифрового следа", интерактивные симуляции.

## Стек технологий
- **Vite** + **React 19** + **TypeScript**
- **Tailwind CSS v4** (для стилизации и адаптивности)
- **React Router v7** (для навигации)
- **Recharts** (для графиков)
- **exifr** (для локального чтения метаданных фотографий)
- Без бэкенда. Прогресс сохраняется локально в браузере (localStorage).

## Как запустить локально (Dev Server)

1. Убедитесь, что у вас установлен Node.js (желательно v18+).
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
4. Откройте в браузере ссылку (обычно `http://localhost:5173`).

## Как собрать для продакшена (Статика)

Для того чтобы загрузить сайт на хостинг (например, Vercel, Netlify, GitHub Pages) или открывать его локально без сервера:

1. Выполните сборку:
   ```bash
   npm run build
   ```
2. В результате появится папка `dist`. Это полностью статический сайт.
3. Вы можете закинуть содержимое папки `dist` на любой статический хостинг.

> **Примечание:** Если вы хотите открывать сайт локально (просто кликнув `index.html` в папке `dist`), вам может потребоваться локальный сервер (например, расширение Live Server в VS Code), так как браузеры блокируют некоторые ES-модули по протоколу `file://`.

## Как редактировать контент

Весь текстовый контент проекта вынесен в JSON-файлы, чтобы его было легко изменять без необходимости копаться в коде React-компонентов. Все файлы лежат в папке `src/data/`:

- `src/data/project.json` — Информация о проекте (автор, руководитель, цели, гипотеза). Отображается на странице "Жоба туралы".
- `src/data/survey.json` — Результаты школьного опроса (вопросы, проценты). Отображается на странице "Нәтижелер" в виде диаграмм.
- `src/data/theory.json` — Теоретическая база (что такое цифровой след, виды, кто видит).
- `src/data/rules.json` — Правила кибергигиены.
- `src/data/simulations.json` — Вопросы, сценарии и тексты для симуляций (игры).

Просто откройте нужный `.json` файл в любом текстовом редакторе и поменяйте текст. После сохранения изменения автоматически отобразятся на сайте.

## Особенности
- **Локальная обработка EXIF:** В симуляции работы с фото данные пользователя никуда не отправляются. Библиотека `exifr` работает исключительно в памяти браузера.
- **Режим презентации:** В шапке сайта есть иконка монитора. При нажатии на неё шрифты на всем сайте увеличиваются, что делает его удобным для показа через проектор при защите проекта.
